# 📦 Sistema de controle de estoque

Esse projeto é um sistema desenvolvido para o controle de um pequeno estoque de alguns produtos.

## 📌 Objetivo do programa

O programa tem como objetivo controlar o estoque de 3 produtos diferentes: teclado, mouse e monitor, utilizando uma condição de alerta para identificar produtos com estoque inferior a 5 unidades.

## ⌨️ Linguagem de programação utilizada no programa
A linguagem utilizada durante o desenvolvimento do programa foi o Python.

## 🛠️ Tecnologias utilizadas
Python 3
Visual Studio Code
GitHub

## 🎯 Conceitos utilizados

Durante o desenvolvimento do programa foram utilizados conceitos básicos de Python, como:

- Listas;
- Matrizes;
- Índices;
- Estrutura de repetição `for`;
- Estrutura condicional `if`;
- Função `input()`;
- Conversão de dados com `int()`.

## 👨‍💻 Execução do programa 

### 📋 Pré-requisito
O pré-requisito para a execução do programa é o **Python 3** instalado na máquina.

### ⚙️ Passo a passo 
O usuário deve inserir:
- A quantidade de teclados disponíveis no estoque
- A quantidade de mouses disponíveis no estoque
- A quantidade de monitores disponíveis no estoque
Ao final da execução o programa irá alertar se o estoque dos produtos está abaixo do limite imposto (5 unidades).
